# 房务通 · 单栋出租楼管理系统

房务通是一套面向单栋出租楼的轻量管理工具，用于集中管理房间、月度水电数据和租金收据。系统采用响应式单页面设计，可在电脑和手机浏览器中使用。

## 主要功能

- 房间管理：查看在租、空置房间，登记入住、退租及房客固定费用。
- 水电录入：支持单间抄表、固定表格批量导入和自由手写三列照片识别。
- 租金收据：支持单张或批量开具、最终效果预览、PNG 下载和历史记录批量下载。
- 收据模板：可设置楼栋名称、收据抬头、默认收款人、默认落款日期和房租金额前缀。
- 数据关联：收据会自动读取对应房间的租金、房客费用和当月水电费用。
- 数据备份：支持把当前设备的全部业务数据导出为 JSON，并在其他电脑或手机完整恢复。

## 数据保存说明

业务数据保存在当前浏览器的本地存储中，不会自动上传到服务器。更换浏览器、清理浏览器数据或更换设备后，原数据不会自动同步，请在操作前注意保留必要记录。

## 本地运行

需要 Node.js `22.13.0` 或更高版本。

```bash
npm install
npm run dev
```

构建正式版本：

```bash
npm run build
```

生成可直接上传到静态托管的版本：

```bash
npm run build:static
```

生成结果位于 `dist-static/`，包含根目录 `index.html` 和 `/ocr/` 下的离线手写识别资源。

运行自动检查：

```bash
npm test
```

2. 在腾讯云备用网址打开同一页面，选择该 JSON 文件。

## 使用提醒

- 手写水电识别结果必须经过人工核对后再入账。
- 批量开具或下载收据前，请确认账期、金额和落款日期。
- 备份文件包含租客姓名、电话和账务资料，请妥善保管，不要发送给无关人员。
- 恢复默认数据会清除当前浏览器中保存的房间、水电和收据记录。
